== Description ==

KPI Dashboard is a powerful WordPress plugin that provides a complete KPI (Key Performance Indicator) management system for businesses with up to 100+ employees.

**Key Features:**

* Standalone login system at domain.com/kpi
* 4-level user role hierarchy (Super Admin, Department Head, Manager, Staff)
* Department and position management with hierarchical structure
* Flexible KPI definitions (department/position/personal level)
* Data entry with approval workflow
* Multiple dashboard views (company, department, personal, comparison)
* Performance insights (best performers, areas needing attention)
* Advanced analytics with YoY, MoM, QoQ comparisons
* Customizable notifications and alerts
* Report generation (PDF, Excel, CSV)
* Scheduled automated reports
* 3-year historical data retention
* Dark mode support
* Fully responsive design
* Audit trail for compliance

**Perfect For:**

* Medium-sized businesses (50-200 employees)
* Companies tracking multiple departments
* Organizations requiring approval workflows
* Teams needing performance analytics
* Businesses with compliance requirements

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/kpi-dashboard/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Navigate to domain.com/kpi to access the KPI Dashboard
4. Default login: admin / admin (change immediately!)

== Frequently Asked Questions ==

= Does this work with existing WordPress users? =

Yes, you can link KPI users to WordPress users or create standalone KPI users.

= How much data can the system handle? =

The system is optimized for 3 years of historical data across multiple departments and users.

= Can I customize the KPIs? =

Absolutely! You can create custom KPIs with various metric types (numbers, percentages, ratios, custom units).

= Is the data secure? =

Yes, the plugin includes JWT authentication, role-based access control, audit logging, and follows WordPress security best practices.
